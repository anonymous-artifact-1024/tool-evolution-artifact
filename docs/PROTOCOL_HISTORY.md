# Protocol history and release policy

This repository is a curated release snapshot rather than a copy of the
engineering workspace. It contains only the final protocol and the data used
for the reported main analysis.

Candidate model configurations, dry runs, interim estimates, teacher-review
workbooks, superseded activation records, IDE state, caches, and failed source
preparation artifacts are intentionally excluded. The final schedule,
protocol, scoring contract, execution activation, result tables, log manifest,
and cryptographic checks remain in `data/provenance/`.

The 20-task pre-experiment validated the protocol and engineering pipeline. It
was not used for main-study inference, service-model effect selection, or
result-driven tuning. The 230-task main split has zero overlap with it.
